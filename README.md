# 🛒 বাজার দর | BazarDor

**BazarDor** is a Bangladesh-focused market price tracking web application that helps users explore the latest prices of essential daily products. Users can browse products by category, compare prices, view price changes, and explore product details through a clean, responsive interface.

## ✨ Key Features

1. **📊 Product Price Tracking** — View today's prices and compare them with previous prices to understand market changes.
2. **📂 Category-Based Browsing** — Explore essential products by category, making it easier to find specific items.
3. **🔍 Product Details** — View individual product information, price summaries, and market price comparisons.
4. **↕️ Price Sorting** — Sort products from lowest to highest price or highest to lowest price.
5. **🔐 User Authentication** — Sign up and sign in using email and password, with Google and GitHub authentication options.
6. **📱 Responsive Design** — Browse the application on mobile phones, tablets, laptops, and desktop computers.
7. **🔔 User Feedback** — Receive notifications for relevant actions through toast messages.

## 🛠️ Technologies Used

* **Next.js 16** — React framework with App Router
* **React** — Component-based user interface
* **TypeScript** — Type-safe JavaScript
* **Tailwind CSS** — Utility-first styling
* **DaisyUI** — UI components and styling utilities
* **Better Auth** — Authentication
* **MongoDB** — Database for authentication data
* **React Toastify** — Toast notifications
* **Lucide React** — Icons
* **REST API** — Product and category market data
* **Vercel** — Deployment platform

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env.local` file in the project root and configure the environment variables required by your application.

   Add your MongoDB connection string, Better Auth configuration, and Google/GitHub OAuth credentials as required by your setup. Never commit secret values to GitHub.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open http://localhost:3000 in your browser.
